## Application rules
- Keep corporate wellness content in one shared page module and one structured configuration; the root redirects to the dedicated content route to avoid duplicate content.
- Store public enquiries only through a schema-validated server function with a handler-local privileged client; no browser access or public lead-reading policies, to protect contact data.
- Keep domain-dependent notifications and production canonical configuration disabled until verified, so requests never claim an unperformed delivery.
